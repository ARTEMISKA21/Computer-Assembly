# Computer Assembly

Приложение для сборки, проверки компьютера и покупки компонентов. Оно позволяет пользователям получать информацию о системе, выбирать компоненты и сохранять их в списке.

## Установка
Для запуска приложения вам потребуется Python 3.7 или выше. Убедитесь, что у вас установлены следующие библиотеки:
Вы можете установить необходимые библиотеки с помощью pip.
- `customtkinter`
- `PIL` (Pillow)
- `psutil`
- `platform`
- `cpuinfo`
- `subprocess`
- `re`
- `tkinter.font`
- `mistralai`
